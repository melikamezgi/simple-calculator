# simple-calculator

This is a simple calculator project made with Python and Tkinter.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Shows an error message for invalid inputs
- Simple graphical user interface (GUI)

## How to Run

1. Install Python on your computer.
2. Download the `calculatormenu.py` file.
3. Run the file using Python.
4. Enter two numbers.
5. Click one of the operation buttons to see the result.

## Tools Used

- Python
- Tkinter

## About the Project

I created this project to practice basic Python programming and working with Tkinter.

The calculator uses `if/elif` statements to perform calculations and `try/except` to handle invalid inputs.
